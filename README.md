# FB Ads API

IPython notebooks exploring the [Facebook Ad Library API](https://www.facebook.com/ads/library/api/).

## Overview

Analysis of sponsored ads targeting Australian users (2020–2024) using PySpark on a Hadoop cluster. Covers data loading, pre-processing, and exploratory analysis of political advertising activity across the dataset period.

## Contents

- `docs/` — project notes and assignment brief

## Requirements

- PySpark
- Jupyter / IPython
- Access to HDFS dataset
